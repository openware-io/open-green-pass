## 生成范围三种模式

- **项目全量**：项目下全部已确认服务。
- **仓库全量**：选中一个仓库，生成该仓库下全部已确认服务；使用该仓库默认分支；不生成其他仓库。
- **指定服务**：手动勾选服务，逐服务选择分支/Tag。

## 交互

- 模式切换旁边提供仓库下拉；每个仓库显示服务数。
- 仓库全量摘要显示仓库 URL、默认分支、服务数、DSH 任务数。
- 底部固定操作条按模式显示：
  - 项目全量生成 N 个服务
  - 生成该仓库 N 个服务
  - 生成 N 个服务
- 每次点击创建新批次，可重复。
- 全量模式不展示单服务勾选和 Tag 轴心。
