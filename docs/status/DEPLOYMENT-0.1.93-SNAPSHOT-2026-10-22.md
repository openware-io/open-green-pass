## 原型内容

本版只做原型/UI，不改变后端生成与执行链路；数据为原型数据。

### 1. 缺陷中心（新增一级菜单 `/findings`）

- 缺陷列表：级别、标题、模块/端点、状态、负责人、证据完整度、关联运行、更新时间。
- 筛选：搜索、P0-P3、状态。
- 详情抽屉：
  - 期望 vs 实际
  - 证据链：请求、响应、日志、Trace
  - 根因分析
  - 修复建议（只读，可复制，不写源码）
  - 关联覆盖 Cell、流转记录
- 操作：确认缺陷、标记误报、标记待回归、模拟创建工单。
- 明确标识：`源码只读`、`缺陷建议不写回仓库`、`不提交 PR`。

### 2. 测试执行页（`/exec`）

- 新增“缺陷候选与归因”卡片：产品缺陷/环境问题/用例缺陷分类、证据完整度、状态。
- 入口“进入缺陷中心”。
- 保留原有真实运行控制与执行清单。

### 3. 用例生成页（`/generation`）

- 新增“覆盖计划”卡片：87 端点、18 模块、412/428 覆盖 Cell、96.3% 规划覆盖、分类 chips、未覆盖 16。
- 明确 `源码只读 · 原型数据`。
- 原有生成范围、代码引用、批次流程不变。

### 4. 质量门禁（`/gate`）

- 新增“缺陷与覆盖门禁”卡片：
  - P0/P1 未关闭 2 → 阻断
  - 必需 Cell 覆盖 96.3% → 未达标
  - 误报率 2.1% → 通过
- 入口“查看未闭环缺陷”。

### 5. 测试报告（`/report`）

- 新增“缺陷与建议摘要”：确认缺陷、待确认、有修复建议、覆盖缺口。
- 明确报告结构包含缺陷证据与只读修复建议。

### 6. 导航与阶段条

- 测试治理下新增“缺陷中心”。
- 对象阶段条新增“缺陷中心”（5 未闭环）。
- 路由 `/findings` 已接入 `app.tsx`。
