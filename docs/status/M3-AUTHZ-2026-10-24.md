# M3 权限维度覆盖：非管理员 token（2026-10-24）

## 机制

HTTP Runner 支持受控的 case 环境引用：

```json
"headers": {"Authorization": "env:GP_CASE_NONADMIN_TOKEN"}
```

只允许 `GP_CASE_` 前缀，避免用例读取任意进程环境。

## 数据

- 使用测试环境 JWT secret 为普通用户 `s3b002319` 生成短期 token
- 存入 Kubernetes Secret `gp-case-auth`
- 通过 `GP_CASE_NONADMIN_TOKEN` 注入 server/worker
- 用例只引用 env 名称，不把 token 写进用例脚本

## 执行

为 61 个未映射的 `authz` Cell 创建非管理员拒绝用例：

```text
Authorization: env:GP_CASE_NONADMIN_TOKEN
expected 401
```

run `2908158313598976`：

```text
61 cases
122 results（attempt_seq 1/2，存在重复执行）
全部 pass
```
