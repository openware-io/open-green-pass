# M2 进度：执行失败归因闭环（2026-10-22）

## 已完成

### 归因 → 缺陷

- `POST /api/runs/{id}/triage`
  - 读取 `run_case_result`
  - 校验失败/阻断状态
  - 生成 finding（仓库/提交/期望/实际/根因/证据摘要）
  - 回写 `run_case_result.failure_class='product'`、`finding_id`
- `GovernanceFindingPort` 跨域适配：
  - execution 只依赖 FindingPort
  - governance 负责 finding 创建/去重/审计
- `CaseResult` 增加 `failure_class`、`finding_id`
- 运行结果查询/保存已包含这两个字段
