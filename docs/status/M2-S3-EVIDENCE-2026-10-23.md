# M2：S3 证据预签名读写（2026-10-23）

## 已实现

- S3 兼容对象存储客户端：`minio-go`，连接 SeaweedFS S3 gateway。
- Bucket 自动创建：`gp-evidence`。
- API：
  - `POST /findings/{id}/evidence/presign`
  - `GET /findings/{id}/evidence/{eid}/download-url`
- 预签名 PUT 有效期 15 分钟。
- `storage_uri` 固定为 `s3://gp-evidence/<team>/<finding>/<id>-<sha12>`。
- 只允许在元数据校验通过后签 URL（kind/mime/size/sha256）。

## 验证

finding `2903529658814464`：

```text
presign PUT  -> 201
upload        -> 200
metadata POST -> 201, evidence 2906585072930816
download URL  -> 200
download body -> "hello evidence"
```

## 当前限制

- 预签名 URL 主机是集群内 `gp-seaweedfs.gp.svc.cluster.local:9000`，浏览器不可直接访问。
- 浏览器上传需要 GP S3 入口或服务端代理；当前验证是在集群内 Node 进程完成。
- 生产环境应配置外部可达的 S3 endpoint，并保持签名主机一致。

## 配置

`gp-app-config` 已包含：

```text
GP_MINIO_ENDPOINT=gp-seaweedfs.gp.svc.cluster.local:9000
GP_MINIO_KEY=gpminio
GP_MINIO_SECRET=***
GP_EVIDENCE_BUCKET=gp-evidence
```
